# Sala Audio - Museo Virtual

Este trabajo de final de grado consiste en un entorno virtual que desarrollé en Unity y Spatial. Esta última herramienta es una plataforma de metaverso que cerró servidores, de modo que ya no se puede acceder al espacio virtual.
